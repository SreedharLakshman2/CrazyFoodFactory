# Crazy Food Factory

A colorful kids cooking game for iPhone (iOS 17+). Children run a chaotic food factory, tap ingredients onto pizza, burgers, ice cream, donuts, and sandwiches, and giggle through funny factory mishaps.

Made by Sai Laksha Technologies.

## Play

1. Open `CrazyFoodFactory.xcodeproj` in Xcode.
2. Choose an iPhone simulator or device.
3. Run the Crazy Food Factory scheme.

The game works fully offline. Progress and sound settings stay on the device.
