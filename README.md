# Crazy Food Factory / Kido Chef

A colorful kids cooking game for iPhone and iPad (iOS 17+). Children tap ingredients onto pizza, dosa, nachos, and many more dishes, then learn what those foods are in Ingredient School.

The App Store name is **Kido Chef**. Made by Sai Laksha Technologies (studio: sreeo).

## Play

1. Open `CrazyFoodFactory.xcodeproj` in Xcode.
2. Choose an iPhone simulator or device.
3. Run the CrazyFoodFactory scheme.

The game works fully offline. Progress and sound settings stay on the device.
